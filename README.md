# Nodus

Enterprise-grade logistics and fleet management platform. Built with a focus on real-time data, high performance, and clean architecture.

## Tech Stack
- **Angular 20** (Zoneless + Signals)
- **Tailwind CSS**
- **RxJS** for telemetry streams
- **Leaflet** for geospatial visualization

## Features
- Real-time fleet tracking and telemetry monitoring.
- Domain-driven asset management and lifecycle.
- Dynamic routing and status orchestration.

## Development
1. `npm install`
2. `npm start`

Refer to `docs/ARCHITECTURE.md` for detailed technical specifications and design patterns.
